# Built-in model registry

- `models/*.yaml` — the catalog, written by people (03 §1.1, 06 §1.1). **Never put `size` or `sha256` here**: the schema rejects them.
- `runtimes/*.yaml` — runtime packs (06 §1.1, 08 §4.2). `builtin: true` packs ship inside the installer.
- `gpu_classes.yaml` — memory bandwidth / FP16 throughput per GPU class for speed priors (06 §1.4).
- `pins.lock` — generated by `.github/workflows/registry-pin.yml` (ADR-0002): the 40-hex commit, size and sha256 of every file of every pinned variant. Do not edit by hand; review the bot PR diff instead.

All VRAM, speed and size numbers in the catalog are **estimates** from the specs (marked 【估算】 there) until M0 / benchmark runs replace them with observations. Variants without a lock entry load as `unpinned`: they are never recommended and cannot be downloaded (`MODEL_NOT_PINNED`).
