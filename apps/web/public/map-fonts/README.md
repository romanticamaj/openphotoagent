# Map glyphs

Latin and punctuation glyph ranges of Noto Sans Regular / Medium / Italic for the offline street map (ADR-0037),
from protomaps/basemaps-assets at commit 028c18f713baecad011301ff7a69acc39bcc2ae7. Noto Sans is licensed under the
SIL Open Font License 1.1. Chinese characters are drawn with the system font (MapLibre `localIdeographFontFamily`).
